# Changelog

All notable changes to the bridge, newest first. Versions follow
[semantic versioning](https://semver.org/): the major number changes when an
upgrade needs you to do something, the minor number when features are added and
the patch number for fixes.

Releases are cut from the Actions tab — see [docs/releases.md](docs/releases.md).
